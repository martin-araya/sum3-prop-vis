# AuditChain – Sistema de Auditorías

## Descripción
AuditChain es una propuesta de sistema de auditoría digital que permite gestionar, supervisar y ejecutar auditorías mediante una plataforma web y una aplicación móvil.

## Objetivo
Desarrollar una solución tecnológica que permita mejorar el control y seguimiento de auditorías en organizaciones.

## Tecnologías utilizadas
- Flutter (aplicación móvil)
- FastAPI (backend)
- PostgreSQL (base de datos)

## Integración del sistema
- Web: administración y visualización de datos
- Mobile: ejecución de auditorías en terreno
- Backend: conexión entre sistemas
