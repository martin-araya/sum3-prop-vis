# Proyecto AuditChain

---

## Descripción

AuditChain es una propuesta de sistema digital orientado a la gestión de auditorías dentro de una organización. La solución contempla una plataforma web para la administración y supervisión de auditorías, junto con una aplicación móvil para la ejecución de estas en terreno.

El sistema busca centralizar la información, mejorar la trazabilidad y facilitar la toma de decisiones mediante la visualización de métricas y estados de auditorías en tiempo real.

---

## Problema

Actualmente, muchas organizaciones gestionan sus procesos de auditoría de forma manual o mediante herramientas no integradas, lo que genera diversas problemáticas operativas y de control.

| Problema identificado        | Descripción |
|----------------------------|------------|
| Pérdida de información     | Registros manuales o dispersos dificultan el control |
| Baja trazabilidad          | No existe seguimiento claro de auditorías realizadas |
| Falta de control en tiempo real | No se puede visualizar el estado actualizado |
| Dificultad en la toma de decisiones | Información poco estructurada |

Estas problemáticas impactan directamente en la eficiencia y control de los procesos internos.

---

## Objetivo

Desarrollar una propuesta tecnológica que permita mejorar el control, seguimiento y ejecución de auditorías mediante una solución integrada entre plataforma web y aplicación móvil.

---

## Usuarios del sistema

El sistema AuditChain está diseñado para dos tipos principales de usuarios, cada uno con funciones específicas dentro de la plataforma.

| Usuario        | Plataforma | Funciones principales |
|---------------|----------|----------------------|
| Administrador | Web      | Gestiona auditorías, visualiza métricas y supervisa el sistema |
| Auditor       | Móvil    | Ejecuta auditorías en terreno y registra resultados |

Cada usuario interactúa con el sistema desde una interfaz adaptada a sus necesidades, permitiendo una mejor experiencia de uso.

---

## Funcionalidades principales

El sistema contempla un conjunto de funcionalidades orientadas a la gestión y control de auditorías.

| Funcionalidad | Descripción |
|--------------|------------|
| Dashboard    | Visualización de métricas de auditorías |
| Gestión de auditorías | Creación y control de auditorías |
| Estados      | Seguimiento (completado, pendiente, en proceso) |
| Registro de resultados | Ingreso de información por parte del auditor |
| Reportes     | Análisis de desempeño y resultados |

Estas funcionalidades permiten mejorar el control y la toma de decisiones dentro de la organización.

---

## Tecnologías utilizadas

Para el desarrollo de la propuesta se seleccionaron tecnologías modernas que permiten construir un sistema escalable, eficiente y adaptable.

| Tecnología  | Rol en el sistema |
|------------|------------------|
| Flutter    | Desarrollo de la aplicación móvil |
| FastAPI    | Backend para gestión de datos y lógica |
| PostgreSQL | Base de datos relacional |
| GitHub     | Control de versiones y repositorio del proyecto |

Estas tecnologías permiten una correcta integración entre los distintos componentes del sistema.

---

## Alcance del proyecto

El proyecto contempla el diseño y prototipado de la solución, incluyendo la creación de mockups funcionales, definición de arquitectura y estructura del sistema.

No se considera en esta etapa la implementación completa en producción, sino una validación de la propuesta tecnológica y su funcionamiento conceptual.
