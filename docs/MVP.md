# MVP - Funcionamiento Mínimo Viable

---

## Descripción

El sistema AuditChain cuenta actualmente con un prototipo funcional que representa las principales características de la solución propuesta. Este MVP (Producto Mínimo Viable) permite visualizar el comportamiento general del sistema y validar la propuesta antes de su implementación completa.

---

## Componentes implementados

El prototipo contempla los siguientes componentes principales:

| Componente        | Estado | Descripción |
|------------------|--------|------------|
| Dashboard Web    | Implementado | Interfaz visual con métricas y estado de auditorías |
| Mockups Móviles  | Implementado | Diseño de la aplicación móvil para auditores |
| Navegación       | Parcial | Flujo de navegación entre vistas principales |
| Backend (API)    | Estructura | Definición conceptual del backend |
| Base de datos    | Estructura | Modelo de datos definido (PostgreSQL) |

---

## Funcionalidades disponibles

El MVP permite representar las funcionalidades principales del sistema:

| Funcionalidad | Estado | Descripción |
|--------------|--------|------------|
| Visualización de métricas | Activo | Dashboard con datos simulados |
| Listado de auditorías | Activo | Visualización de auditorías |
| Estados de auditoría | Activo | Indicadores de estado (pendiente, completado) |
| Interacción básica | Parcial | Simulación de acciones del usuario |

---

## Limitaciones del MVP

Dado que se trata de una versión inicial, existen ciertas limitaciones:

- No existe conexión real a base de datos
- No se ha implementado completamente el backend
- Los datos utilizados son simulados
- No hay autenticación de usuarios

---

## Objetivo del MVP

El objetivo principal del MVP es validar la propuesta de solución, permitiendo:

- Visualizar la estructura del sistema
- Comprender la interacción entre los usuarios
- Evaluar la experiencia de usuario
- Identificar mejoras antes de la implementación final

---

## Proyección

Como siguiente paso, se propone:

- Implementar conexión real con backend
- Integrar base de datos PostgreSQL
- Desarrollar la lógica completa del sistema
- Realizar pruebas de funcionamiento
